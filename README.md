# 卖场平面图

面向手机和平板的卖场布局工具。首次打开会载入一个可编辑的示例卖场。

## 打开与部署

将 `index.html`、`style.css`、`app.js` 放在同一目录，直接在现代浏览器中打开 `index.html` 即可离线使用。部署到 GitHub Pages 时，在仓库的 **Settings → Pages** 选择发布分支和根目录 `/ (root)`。应用无需构建，也无需服务器接口或外部资源。

## 绘制与摆放

1. 点击 **新建场地**。矩形以毫米输入宽和长。多边形可套用 L 形或凸形，或按边界顺序添加和编辑坐标行。也可选择 **在画布上绘制**，逐点点击后点击 **闭合图形**，或点回首点。边线须围成有效区域。
2. 点击或轻触场地内部即可选中场地。多边形选中后可拖动顶点。图中显示边长，场地信息面板显示面积及外接尺寸。
3. 从 **货架库** 点击货架，将它放在视图中心附近，遇到已摆放的货架会寻找相邻空位。**流水台** 会一次放入两张桌，前桌在后桌下方居中相邻。点击货架后可拖动、旋转 90°、复制或删除。在 **属性** 中可更改名称、尺寸、中心坐标、任意旋转角度和颜色。图中会显示货架名称，空间足够时会附上尺寸。
4. 单指拖动空白区域平移，双指捏合缩放并可同时平移。桌面可用鼠标拖动及滚轮缩放。右下角可缩放和适应画布。底部可切换网格、吸附及 10、50、100、500 mm 间距。开启吸附后，拖动货架可对齐货架边、墙边和中线，网格为后备。吸附时显示参考线，拖出吸附范围即可自由摆放。绘制或拖动顶点时也可对齐其他顶点。坐标原点是场地外接矩形左上角，X 向右，Y 向下。
5. 点击画布上方的按钮撤销或重做。桌面也支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z，以及 Ctrl/Cmd+Y。当前会话最多保留 60 步。

## 保存和交换文件

- **方案** 管理本机的多个方案，可打开、复制、重命名和删除。方案和货架库自动保存到当前浏览器。不同设备、浏览器或网站地址各有自己的数据，迁移时请导出 JSON。
- **导出** 可下载带标题、比例尺、标注和货架名称的无网格 PNG，或包含当前方案及货架库的 JSON。顶部 **导入** 会把 JSON 作为新方案打开并合并货架库。
- 货架库的 **＋** 新增单件货架。每个条目都有 **编辑** 和 **删除** 按钮，单件货架可修改名称、宽、深和颜色。库内编辑或删除只影响后续摆放，方案内已放置的货架可以单独编辑。
- 点击 **新建组合**，从库内单件货架中选择并逐个添加至少两件成员。同一种货架可重复添加。可编辑组合名称，以及每件成员的名称、宽、深、颜色和中心偏移。偏移单位为毫米，以组合摆放点为原点，X 向右、Y 向下。组合保存各成员的副本，摆放后各成员是独立货架。
- **导入库** 可合并 UTF-8 CSV 或 JSON。CSV 用于单件货架，表头使用 `name,width,depth,color`。JSON 接受货架对象数组或含 `library` 数组的对象。单件使用 `name,width,depth,color` 字段。组合使用 `name,members`，每个成员包含单件字段以及 `offsetX,offsetY`。尺寸为正数，颜色用十六进制（如 `#8ac9ba`）。**导出库** 下载 JSON。
- 没有已保存的货架库时，应用会加入 **流水台** 组合和以下单件货架。已有货架库（包括空库）会原样载入。点击 **恢复默认货架** 并确认，可补回缺少的默认条目，同时保留已编辑的默认条目和自建货架。

| 三层架 | 1200 × 450 |
